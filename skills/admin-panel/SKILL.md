# Admin Panel

Вторая админка лежит в `%USERPROFILE%\Desktop\opencode-boost\admin\`.

## Запуск

```powershell
& "%USERPROFILE%\Desktop\opencode-boost\admin\start.cmd"
```

Или напрямую:

```powershell
node "%USERPROFILE%\Desktop\opencode-boost\admin\server.js"
```

Открыть: http://127.0.0.1:8787

## Что умеет

- Статус сервиса и версию (`/api/info`)
- Список сессий, агентов, навыков, плагинов, MCP, моделей
- Перезагрузку конфигурации
- Быстрые ссылки на конфиги и логи

## Как работает

Дашборд не знает пароль сервиса: сервер запускает `opencode-cli.exe api <method> <path>`
через `child_process`, используя встроенную авторизацию CLI.

## Безопасность

Сервер слушает только `127.0.0.1`. Не открывайте порт наружу и не добавляйте
в дашборд вывод секретов (ключи, токены, пароли).
