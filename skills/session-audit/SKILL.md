# Аудит сессий

Плагин `session-audit-tools` читает `~/.local/share/opencode/log/opencode.log` **только на чтение**.
Секреты, токены и пути к домашней папке в отчёте заменяются на заглушки.

## Инструменты

- `sessionaudit.scan({ hours?, all?, limit? })` — короткая сводка без записи файлов. По умолчанию 168 часов.
- `sessionaudit.patterns({ hours?, all? })` — повторяющиеся сигналы с фиксом и тестом для каждого.
- `sessionaudit.report({ hours?, all? })` — полный Markdown-отчёт в `brain/reports/session-audit-YYYY-MM-DD.md`.

CLI без агента:

```powershell
node "$env:USERPROFILE\Desktop\opencode-boost\scripts\session-audit.js" --hours 168
node "$env:USERPROFILE\Desktop\opencode-boost\scripts\session-audit.js" --all --save --json
```

## Что ищется

- Повторяющиеся `ERROR`/`WARN` и шумные сообщения, сгруппированные по нормализованному тексту.
- Всплески: 5+ одинаковых событий за 2 минуты; сессии с максимальным числом шагов.
- Перезапуски CLI (`cli starting`) по дням и пиковому часу.
- Рекомендации по типам: отсутствующая папка сессии, MCP-мост, квота, устаревший клиент, сеть, разрешения.

## Правила

1. Сначала `scan`, затем `patterns`, и только потом `report` — не засорять мозг без нужды.
2. Отчёт не содержит значений секретов; если нашёл секрет в логе — не копируй его в ответ.
3. Рекомендации не применяются автоматически: propose fix, затем отдельно запросить согласие.
4. Важные повторяющиеся проблемы дублируй через `brain.save(topic, text, long?)`.
5. Для реальных исправлений используй `oc-doctor` / `oc-doctor-fix`, а не прямые правки логов.
