# Повторный аудит (reaudit)

Скрипт `scripts/reaudit.js` проверяет 24 конкретные находки из отчётов
`ai-os-new-deep-audit.md` и `ai-os-new-matrix-audit.md` и сравнивает их с базовой линией.

## Когда использовать

- После того как выложена новая версия проекта (например, исправления с второго компьютера).
- Когда нужно быстро понять: закрылась ли конкретная уязвимость/баг, нет ли регресса.

## Вызов

```powershell
cd "C:\Users\deda donik\Desktop\opencode-boost"
& 'C:\Program Files\nodejs\node.exe' scripts/reaudit.js "<путь к проекту>" --name ai-os-new
```

Флаги:

- `--json` — только JSON в stdout, отчёт не сохраняется.
- `--no-save` — не сохранять Markdown-отчёт.
- `--refresh-baseline` — перезаписать базовую линию текущим состоянием.
- `--baseline <путь>` — использовать другую базовую линию.

## Что проверяется

24 проверки: P0-1…P0-9, P1-1…P1-12, P2-1…P2-3. Для каждой у записи есть
список `open`-паттернов (старый код) и `fixed`-паттернов (ожидаемое исправление),
иногда с окном соседних строк. Статусы: `open`, `fixed`, `mixed`, `uncertain`, `missing`, `manual`.

Результат:

- `brain/reports/reaudit-baseline-ai-os-new.json` — базовая линия.
- `brain/reports/ai-os-new-reaudit-YYYY-MM-DD.md` — отчёт с таблицей и diff.

## Правила

1. Скрипт только читает файлы проверяемой папки. Не запускай в ней install/build/test/git.
2. Не копируй отчёты и секреты внутрь проверяемого проекта.
3. Значения секретов в отчёт не попадают — они маскируются.
4. Статус `uncertain` означает «паттерн исчез, но подтверждения исправления нет» — смотри файл вручную.
5. Важные изменения сохраняй через `brain.save(topic, text, long?)`.
