# MEMORY — индекс второго мозга

> Читай этот файл в начале нетривиальной работы.

## Карта

| Раздел | Назначение |
| --- | --- |
| `memory/LONG_TERM.md` | Факты, которые нужно помнить всегда |
| `memory/YYYY-MM-DD.md` | Дневные логи: что делали, что нашли |
| `knowledge/` | Тематические заметки |
| `decisions/` | Решения с причинами и альтернативами (ADR) |
| `projects/` | Карточки проектов |
| `graphs/` | Сгенерированные графы `.mmd`, `.json`, `.md` |
| `autonomy/` | Цель, журнал шагов и чекпоинты автопилота |
| `reports/` | Отчёты проверок и аудита |

## Правила записи

- Факт → `LONG_TERM.md`, событие → дневник, решение → `decisions/`.
- Одна идея = одна строка. Формат: `- [HH:MM] тема — суть`.
- Никаких секретов: ключи, пароли, токены сюда не пишем.
- Связи между заметками: `[[ссылки]]` и теги `#тег`.
