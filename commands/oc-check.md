Запусти самопроверку и доложи результат.

1. Выполни `node "%USERPROFILE%\Desktop\opencode-boost\scripts\oc-check.js"` через shell.
2. Прочитай свежий отчёт `~/Desktop/opencode-boost/brain/reports/oc-check-YYYY-MM-DD.md`.
3. Если есть провальные проверки, исправь их точечно (конфиги — через навык `opencode-tuner`) и запусти проверку снова.
4. Коротко перечисли статус по разделам: сервис, плагины, конфиги, мозг, админка, вики.
5. Важные находки сохрани через `brain.save`.
